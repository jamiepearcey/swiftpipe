Synthetic FIN samples
=====================

Hand-written from the SWIFT User Handbook field lists (no upstream source) to
exercise the starter schemas for MT199, 200, 202, 210, 299, 900, 910, 942 and
950, for which no public message file was found. They prove the schema shape and
anchored-sequence grouping only, not real-world coverage. Checked by
`crates/swift-schema/tests/upstream_fixtures.rs`.
